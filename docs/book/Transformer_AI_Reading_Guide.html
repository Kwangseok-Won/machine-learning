코드를 읽기 전에
이 여덟 가지만 알아두세요.

① Tensor = 숫자가 들어 있는 상자

문장 묶음 → 단어 자리 → 특징 숫자

[B,L,D]는 묶음 수 B, 단어 자리 수 L, 특징 수 D입니다. 이 모델의 D는 512입니다.

② shape = 상자의 칸 수

[2, 5, 512]

문장 두 개, 문장마다 다섯 자리, 자리마다 숫자 512개라는 예시입니다. 실제 어휘 번호나 학습 결과는 아닙니다.

③ class와 __init__

설계도 → 부품 조립

class는 부품을 만드는 규칙, __init__은 부품을 처음 만들 때 설정과 하위 도구를 준비하는 곳입니다. self는 지금 만든 부품 자신입니다.

④ forward = 재료가 지나가는 길

model(입력) → forward → 결과

PyTorch의 nn.Module 객체를 함수처럼 부르면 forward가 실행됩니다. x = self.emb(x)도 같은 원리입니다.

⑤ Embedding = 단어 특징 카드

단어 번호 → 숫자 512개

학습 가능한 표에서 단어 번호에 맞는 행을 가져옵니다. 초기 숫자에 사람이 미리 의미 이름을 붙여 둔 것은 아닙니다.

⑥ mask = 보지 않을 칸 표시

패딩 가리기 · 미래 정답 가리기

Encoder는 입력의 패딩을 무시합니다. Decoder의 Self-Attention은 뒤에 있는 목표 정답도 미리 볼 수 없도록 합니다.

⑦ Loss와 gradient

틀린 정도 → 고칠 방향 → 실제 수정

Loss가 틀린 정도를 재고, backward가 수정 방향을 구하고, optimizer.step이 모델 파라미터를 바꿉니다.

⑧ Dropout과 평가 모드

연습 중 일부 가리기 → 평가 때 모두 사용

Dropout은 학습 중 일부 값을 무작위로 0으로 만듭니다. model.eval()에서는 이 가리기를 끕니다. no_grad()는 gradient 기록을 끄는 별도 기능입니다.

읽었는지 확인하기

Embedding은 숫자 512개를 8개 Head로 나누는 블록인가요?

아니요. Embedding은 단어 번호를 특징으로 바꿉니다. Head 분리는 MultiHeadAttention.split의 역할입니다.

N=6이면 위치 표시도 여섯 번 더하나요?

아니요. 임베딩과 위치 더하기는 한 번, EncoderLayer 내부 계산만 여섯 층을 거칩니다.

Encoder의 결과는 독일어 문장인가요?

숫자 메모입니다. Decoder가 이 메모를 참고해 다음 단어 후보의 점수를 만듭니다.
