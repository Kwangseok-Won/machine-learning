③ 정답을 한 칸 어긋나게 준비

Decoder에 주는 것

맞혀야 하는 것

trg[:, :-1]을 입력으로, trg[:, 1:]을 정답으로 씁니다. 각 자리에서는 가림막 덕분에 자기 뒤의 정답을 볼 수 없습니다. 학습은 여러 자리의 점수를 한 번의 forward에서 계산합니다.

④ Encoder → Decoder → 어휘 점수

영어 [B,S] → Encoder 메모 [B,S,512]
↓ 독일어 앞부분과 함께 참고
Decoder → 점수 [B,T,V]

V는 독일어 어휘 수이며 자료의 번호표로 결정됩니다. 결과는 확률로 정규화하기 전의 logits입니다.

현재 평가 코드의 범위

evaluate도 정답 앞부분을 제공하므로 자유 번역 평가와 다릅니다. 또한 get_bleu에 넘기는 자료 구조가 맞지 않아 단어 문자열을 문자 n-gram으로 처리합니다. 기록값을 표준 문장 BLEU로 해석하지 않도록 함수 해설에서 실제 동작을 함께 설명했습니다. 계산 코드는 수정하지 않았습니다.
