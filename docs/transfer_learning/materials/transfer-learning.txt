This run shows the scheduler fix worked: the logged learning rates decrease smoothly after warmup, with no rebound. The schedule advances once per epoch, which is the right cadence for an epoch-based `T_max`; the LR values you log before training are the values used during that epoch. [ch4.9-learning-rate-schedulers.qmd](https://github.com/jshn9515/deep-learning-notes/blob/main/en/ch4-optimization-algorithms/ch4.9-learning-rate-schedulers.qmd)

  * __Warmup__: the FC LR rises from `1e-4` to `5.5e-4` to `1e-3` over epochs 1–3. The `layer4` LR is one tenth of the FC LR, as configured.
  * __Cosine decay__: after epoch 3, the rates decline monotonically. Epoch 29 uses `1.25e-5` for the FC head. Because training stopped before epoch 30, this run didn’t execute the final scheduled epoch; that’s expected with early stopping.
  * __Checkpoint and stopping__: the best validation accuracy is `0.8804` at epoch 23. Epochs 24–29 did not beat it, so patience 6 correctly stops at epoch 29. Since the loop restores the best checkpoint, the final reported `0.8804` is the epoch-23 model’s score—not the epoch-29 model’s score.
  * __Interpret the losses carefully__: training loss is measured on Mixup examples with label smoothing, while validation loss uses ordinary hard labels. They are different objectives, so their values aren’t directly comparable. The training accuracy is measured on the unaugmented training set; reaching 1.0 indicates the small training set is being memorized, though validation accuracy continued improving afterward.
  * __Name the evaluation accurately__: `plot_class_diagnostics(model, val_data, ...)` evaluates the labeled validation set, not the 6,149-image unlabeled test set. Consider changing `Evaluation accuracy` to `Validation accuracy`; `0.8804` is not a measured test accuracy.

Overall, this is a strong validation result, and early stopping selected the correct checkpoint. I’d preserve that checkpoint and avoid tuning further based on the same validation set alone; repeated changes guided by it can make the reported validation score increasingly optimistic.
